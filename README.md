# Retail Sales Forecast Lab

店舗・商品・日付ごとの売上データをもとに、将来の売上を予測するサンプルプロジェクトです。  
データ分析、特徴量設計、時系列予測、モデル評価、可視化、簡易デモ画面までを一通り実装し、実務での売上予測業務を意識した構成にしています。

---

## 1. 概要

このプロジェクトでは、過去の売上実績や販促情報などを使って、今後の売上を予測します。

想定ユースケース:
- 在庫計画の最適化
- 販促施策の検討
- 売上見込みの把握
- 店舗別・商品別の需要変動の可視化

本リポジトリでは、以下を一通り確認できます。

- CSVデータの読み込み
- データ前処理
- EDA（探索的データ分析）
- 特徴量設計
- 時系列を意識した学習・評価
- ベースラインモデルとの比較
- 予測結果の可視化
- Streamlit による簡易デモ画面

---

## 2. 解きたい課題

売上予測は、単に数値を当てるだけではなく、業務判断に使える精度と説明性が重要です。  
このプロジェクトでは、次の課題に対して実務を意識した構成で取り組みます。

- 売上の季節性や曜日傾向を捉える
- 直近売上の流れを特徴量として取り込む
- 未来情報の混入を避ける
- ベースライン予測より改善できているか確認する
- 可視化を通じて結果を説明できる状態にする

## 4. データ概要

想定データ例:

| カラム名 | 説明 |
|---|---|
| date | 売上日 |
| store_id | 店舗ID |
| product_id | 商品ID |
| sales | 売上数量または売上金額 |
| promo | 販促実施フラグ |
| holiday | 祝日フラグ |
| price | 販売価格 |
